## 📖 About The Project

Quiz Master: Trivia & GK offers a **well-structured and engaging quiz experience**. Test your general knowledge and trivia skills with carefully curated questions. Multiple categories ensure a diverse and enriching learning experience. Designed for smooth performance with a simple and user-friendly interface. Enhance your knowledge, memory, and critical thinking skills anytime, anywhere.

### ✨ Key Highlights

- 🎮 **Quality First** - Carefully curated questions for the best experience
- 🌐 **Community Driven** - Built with user feedback and engagement in mind
- 🚀 **Modern Technology** - Powered by the latest web technologies

## 🚀 Getting Started

### Prerequisites

- Node.js (v18 or higher)
- npm or yarn

### Installation

1. Clone the repository
   ```bash
   git clone https://github.com/Ionic-Errrrs-Code/quiz-master-trivia-gk-web-application.git
   ```

2. Navigate to the project directory
   ```bash
   cd quiz-master-trivia-gk-web-application
   ```

3. Install dependencies
   ```bash
   npm install
   ```

4. Start the development server
   ```bash
   npm run dev
   ```

5. Open your browser and visit `http://localhost:5173`

### Build for Production

```bash
npm run build
```
